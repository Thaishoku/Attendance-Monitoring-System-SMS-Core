# Student Attendance Monitoring System with SMS Notification

Core backend logic and database implementation for the **Student Attendance Monitoring System** developed for **Top Link Global College (TLGC)**.

## 📌 Core Features
- **SMS Gateway Integration:** Real-time SMS dispatch using `iProgSMS API` triggered during student attendance entry.
- **Phone Number Sanitization:** Dynamic parsing and formatting of Philippine mobile formats (`09xx` and `+639xx`).
- **Audit Logging:** System logs capturing recipient contact details, sent messages, timestamps, and delivery statuses.

## 🛠️ Tech Stack
- **Language:** C# (.NET Core)
- **Framework:** ASP.NET Core MVC
- **ORM:** Entity Framework Core
- **Third-Party API:** iProgSMS Gateway
